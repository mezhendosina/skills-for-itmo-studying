## Лаба 1. Продвинутый калькулятор

Калькулятор должен вычислять полноценные арифметические выражения с учётом приоритета операций и скобок, а не только схему «число → операция → число → результат».

Обязательная функциональность:

- ввод произвольного выражения: `+ − × ÷`, скобки, вещественные числа, корректный приоритет операций;
- кнопки `=`, `C` (очистка), `⌫` (удалить символ), `%`, `±`;
- история последних 10 вычислений; клик по записи возвращает выражение в поле ввода для редактирования;
- память калькулятора: `M+`, `M−`, `MR`, `MC`;
- сохранение состояния при повороте экрана и других изменениях конфигурации: выражение, история, память, последний результат, состояние ошибки;
- обработка ошибок без падения приложения: деление на ноль, неверная расстановка/количество скобок, два оператора подряд, несколько точек в одном числе, пустое выражение, выражение оканчивается оператором.

Требования к реализации:

- стек на выбор — Swift для iOS или Flutter; функциональные требования одинаковы для обоих;
- логика вычисления выражения должна быть отделена от UI и тестируема независимо;
- интерфейс должен давать доступ ко всем операциям из задания.
