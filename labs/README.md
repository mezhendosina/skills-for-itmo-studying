## Как добавить предмет

1. Создайте папку `labs/<предмет>/` (латиницей, через дефис).
2. Добавьте в неё `README.md` с таблицей лаб: номер, тема, стек/детали, ссылка на файл задания, статус, дедлайн.
3. Файлы заданий (PDF, DOCX и т.д.) кладите рядом, в ту же папку.
4. Впишите новую строку в таблицу выше.
