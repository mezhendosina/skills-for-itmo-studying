## Лаба 1. Что такое баг? (исследовательское тестирование)

Развить наблюдательность и аналитический взгляд на программные продукты до изучения формальных методов документирования. Выбрать любой повседневный сервис (соцсеть, банковское приложение, маркетплейс, госпортал и т.п.), провести 30–40 минут активного исследования и зафиксировать своими словами не менее 5 наблюдений: расхождения между ожидаемым и фактическим поведением, непонятные ошибки, неудобства интерфейса.

Полный текст задания: [lab-01.pdf](lab-01.pdf), слайды для разбора на занятии: [lab-01-slides.pptx](lab-01-slides.pptx).

## Лаба 2. Баг-репорт

Полный текст задания: [lab-02.pdf](lab-02.pdf), слайды: [lab-02-slides.pptx](lab-02-slides.pptx).
