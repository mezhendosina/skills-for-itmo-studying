
# README коллекции ITMO-скиллов

## Цель

Создать практический русскоязычный `README.md`, который кратко объясняет назначение репозитория и позволяет установить всю коллекцию или один выбранный скилл через `skills` CLI. Основная команда:

```bash
npx skills add mezhendosina/skills-for-itmo-studying

```

## Scope

README описывает только два существующих скилла:

- `vkr-latex-check`;
- `fetch-telegram-messages`.

Документ не меняет сами скиллы, не обещает совместимость сверх подтверждённой CLI-документацией и не включает секреты, пользовательские сессии или непроверенные метрики популярности. Отдельный Git-корень `skills` не содержит `openspec/`, поэтому `openspec init` требуется по `AGENTS.md` перед дальнейшей работой в проекте. Инициализация не входит в эту делегированную правку, ограниченную одним проектным документом; владелец основной задачи должен отдельно разрешить этот процессный блокер до реализации README.

## Структура README

1. Название и одно предложение о назначении коллекции.
2. Требование: Node.js версии не ниже `22.20.0` с доступным `npx`.
3. Быстрый старт с интерактивной установкой всей коллекции.
4. Варианты команд:
   - установка одного скилла через `--skill <name>`;
   - глобальная установка для Codex через `--agent codex --global`.
5. Таблица с названием, назначением и ключевыми требованиями каждого скилла.
6. Настройка `fetch-telegram-messages`: Python, зависимости, `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, внешний путь для сессии и состояния, отсутствие read-ack.
7. Ограничения `vkr-latex-check`: проверка по вложенному реестру требований, разделение статического анализа TEX и визуальной проверки PDF, отсутствие гарантии официального нормоконтроля.
8. Короткая проверка установки и ссылка на документацию CLI.

## Источники фактов и команд

- [официальная документация `skills` CLI](https://www.skills.sh/docs/cli) — базовая команда `npx skills add <owner>/<repo>`;
- [репозиторий `vercel-labs/skills`](https://github.com/vercel-labs/skills) — параметры `--skill`, `--agent` и `--global`;
- [`package.json` текущего `skills` CLI](https://github.com/vercel-labs/skills/blob/main/package.json) — минимальная версия Node.js `22.20.0`;
- Git remote текущего репозитория — точный идентификатор `mezhendosina/skills-for-itmo-studying`;
- локальные `fetch-telegram-messages/SKILL.md`, `fetch-telegram-messages/requirements.txt` и `vkr-latex-check/SKILL.md` — назначение, зависимости, настройка и ограничения скиллов.

README не должен приводить меняющиеся числа загрузок или GitHub stars: выбор основного способа установки уже сделан по актуальному исследованию, а инструкция должна оставаться полезной без постоянного обновления статистики.

## Требования к проверке

- Все команды соответствуют актуальному синтаксису первичных источников и используют точное имя GitHub-репозитория.
- Имена скиллов дословно совпадают с полем `name` в их `SKILL.md`.
- README не содержит API hash, session-файлов, локальных секретных путей или утверждения о проверенном живом входе в Telegram.
- Ограничения обоих скиллов отражены явно, без выдуманных возможностей.
- Все относительные ссылки и упомянутые файлы существуют в репозитории.
- Команда `/Users/mezhendosina/.agents/skills/markdown-format/fix_markdown_format.sh --files README.md` завершается успешно, после неё нет пробелов в конце строк, а файл оканчивается переводом строки.
